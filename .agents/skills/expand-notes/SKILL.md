# expand-notes

用于用户要求整理、补充、扩写或完善 `notes/class/` 与 `notes/method/` 的笔记。

1. 先读取根目录 `AGENTS.md` 与用户指定笔记；细节影响准确性时，读取少量相关 Wiki、Raw 或可靠来源。
2. 将已有全部 Markdown 标题视为用户不可变大纲：不得修改标题文字、层级或顺序，不得删除、合并、拆分或重排标题；保留文件名与核心原意；不得重组 `notes/` 文件夹。
3. 在原标题下将关键词、碎句和速记改写为完整可读正文。引用网页或文献时，在相关事实原位插入可访问链接。
4. 确有必要细分时，只能在原标题下新增下一级标题；同级补充只能追加到所有原有同级标题之后。
5. 冒号 `：` 后只有空格或空行时，按 `AGENTS.md` 的个人偏好直接补写。
6. 课堂笔记优先补概念、机制、例子和复习线索；方法笔记优先补步骤、参数、风险、排错和验证标准。
7. 仅在局部无法可靠确认且删除会损失价值时，按 `AGENTS.md` 的行内不确定性格式保留；不得用独立“待验证”章节破坏可读性。
8. 如形成可复用内容，可同步更新最匹配的 Wiki 页、索引与日志，并在回复中说明。
9. 本操作不复制到 Raw；用户检查、返修并明确接受后，才可使用 `note-approve`。
