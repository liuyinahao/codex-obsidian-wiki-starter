# 日常操作手册

以下句子可直接作为对 Codex 的请求。文件名替换成你的实际文件。

## 收集与 ingest

| 目的 | 可直接说 |
|---|---|
| 处理下一条 | `ingest 下一条 Raw 资料；先说明资料和计划更新页面。` |
| 处理指定文件 | `ingest raw/unprocessed/某篇资料.md。` |
| 处理批次 | `把 raw/unprocessed/某个批次/ 作为一个 ingest 单元处理。` |
| 扩大普通 Clip 范围 | `这条普通 Clip 也请读取它的 PDF 与图片后再 ingest。` |
| 批准归档 | `批准刚才的 ingest，归档到 processed。` |
| 健康检查 | `对 Wiki 做一次 lint，只修复低风险链接和索引问题。` |

## 笔记

| 目的 | 可直接说 |
|---|---|
| 整理课堂笔记 | `整理 notes/class/课程/2026-09-15.md，不能改动已有标题。` |
| 整理方法笔记 | `完善 notes/method/某方法.md，补上参数、风险点和排错。` |
| 接受并送入 Raw | `我接受某方法.md 的扩写，请执行 note-approve。` |
| 不接受，继续修订 | `不要 note-approve；保留标题，继续修订这份笔记的……部分。` |

## 查询与沉淀

| 目的 | 可直接说 |
|---|---|
| 基于现有 Wiki 回答 | `基于 Wiki 说明某主题的证据、分歧和未决问题。` |
| 回填好回答 | `把刚才的结论沉淀为研究方向页面，并更新索引和日志。` |
| 建个人分类 | `在 wiki/literature-synthesis/ 下为炎症主题新建分类文件夹；不要移动已有页面。` |

## 如何看待 Codex 的停顿

以下情况应当停下询问或等待你确认，属于正常保护：

- 无法判断资料属于哪类知识页；
- Raw 目标路径冲突；
- 资料需访问登录受限附件；
- 要将 `pending_review` 移到 `processed`；
- 要重组你已建立的笔记或分类目录；
- 要把敏感资料上传外部服务。

若 Codex 跳过上述检查，可提醒：`请按 AGENTS.md 的 ingest/approve 边界执行，不要直接归档。`
