# 个性化设置

这套工作流刻意把“稳定骨架”和“个人偏好”分开。你的偏好写在根目录 `AGENTS.md` 的“个人偏好”部分，让后续 Codex 对话都能看见；不要只把规则留在某个聊天记录中。

## 可以直接改的偏好

### 1. 笔记整理风格

你可以要求：

- 保留或不保留关键词原话；
- 补充内容用长段、短段、表格还是清单；
- 对不确定内容用高亮、脚注或完全不写；
- 是否允许 Codex 新增下一级标题；
- 冒号空位是否应自动补充。

示例：

```markdown
- 不确定内容：只在影响结论时标为 ==待确认==，其余改写为谨慎表述。
- 冒号补全：只在方法笔记中启用；课堂笔记保留空位让我自己填写。
```

### 2. 重点资料规则

默认使用标题末尾 `*`。也可以改成你的符号或 frontmatter 字段，但必须同步修改 `AGENTS.md` 与 `ingest-raw` skill，并记录 History。

示例：

```markdown
- 重点 Clip：frontmatter `reading_depth: full` 时读取附件与外链；其余只读 Clip 本体。
```

### 3. Wiki 分类

你可以在下列目录中按疾病、课题、实验平台或时间创建任意子文件夹：

- `wiki/literature-synthesis/`
- `wiki/experimental-methods/`
- `wiki/research-directions/`

例如：

```text
wiki/literature-synthesis/
  mitochondrial-stress/
  pancreatic-cancer/
wiki/experimental-methods/
  cell-culture/
  imaging/
```

只要顶层类型不变，Codex 就会递归兼容这些分类。你无需让 Raw 保存路径也按相同结构分类。

### 4. 资料类型与页面模板

如果你常处理特定资料，可在 `AGENTS.md` 的“知识图谱与页面规范”补充页面模板。例如临床指南可以增加“适用人群、推荐级别、证据等级”；代码笔记可以增加“运行环境、输入输出、复现步骤”。

## 需要谨慎改、并写 History 的内容

- `raw/unprocessed → pending_review → processed` 状态机；
- 默认保存路径、目录重命名或删除；
- Raw 正文只读边界；
- `.agents/skills/` 的规则；
- 自动读取外链、使用外部服务或隐私边界；
- Codex Panel 等插件配置。

可直接要求：`把以下偏好写入 AGENTS.md，并按底层变更留痕规则新增 History 记录：……`

## 不建议的做法

- 为了分类在剪藏时建立大量 Raw 文件夹；这会破坏简单的入口并增加漏处理风险。
- 用文件路径表达知识关系；优先用 `[[双链]]`。
- 让 Codex 为美观删掉来源冲突或原始资料。
- 修改 skills 却不更新 AGENTS.md；二者会逐渐冲突。
